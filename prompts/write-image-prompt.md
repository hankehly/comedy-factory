# Write Image Prompt

Your task is to write a prompt for a text-to-image model that produces an image to accompany the joke below. The joke text will be rendered onto the image afterwards as a caption by a separate step.

## Rules

The image prompt must:

* Describe a single clear scene that acts as the joke's straight man: it depicts the joke's subject matter played completely straight, letting the caption deliver the punchline. The image itself must not attempt humor.
* Describe the scene concretely and visually — subjects, composition, setting, lighting, and style — in plain descriptive language a text-to-image model can follow.
* Explicitly state that the image contains no text: no words, lettering, signage, labels, logos, or writing of any kind.
* Not include the joke text, the caption, or any words to be rendered in the image.
* Be at most 1000 characters.

## Output

Set `text` to the image prompt and nothing else — no preamble and no explanation.
